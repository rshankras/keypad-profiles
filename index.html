How to import

  1. Install the plugin from the Logi Marketplace, so the imported keys resolve to real actions.
  2. Download the .lp5 for your plugin and platform.
  3. In Logi Options+, open your MX Creative Keypad, then the profile menu (the ⋯ or profile dropdown) → Import Profile → pick the file.
  4. The profile activates whenever its application is in front. Rebind or rearrange any key afterwards.

Import once. Updating or reinstalling the plugin leaves your profile in place.

Codex hook trust

Vizhi installs its own local Codex lifecycle hooks but cannot approve them for you. In Codex, run /hooks, review the Vizhi entries, and trust them. Then start a new session or submit a prompt; the session and approval indicators will become live after the first trusted event. Never bypass hook trust globally.

Claude Console live status

Claude Console adds a status line and five hooks to ~/.claude/settings.json only after you confirm from a live key. Your existing entries are retained and settings.json.claude-console.bak is refreshed before every plugin change.

To remove only Claude Console's entries, hold a live key and choose Turn off, or run bash ~/.claude/claude-console/scripts/uninstall.sh --unwire. This leaves ~/.claude/claude-console/no-autowire, so the plugin stays off until you deliberately turn it on again.

Windows Terminal

Import the Windows-specific profile and run Codex or Claude Code in Windows Terminal. If Terminal is not open, terminal-dependent keys refuse safely; direct typing keys remain available. For classic Command Prompt or PowerShell sessions, set Settings → System → For developers → Terminal to Windows Terminal and start a new session. Elevated sessions cannot be controlled by unelevated Logi Options+.
