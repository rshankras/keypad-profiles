What changed in 2.4.0 / 1.7.0

Claude Console is now Vizhi for Claude Code, iTerm2 is supported alongside Terminal, and the layout files are named after the terminal they bind to. The keys are the same; a layout you imported earlier keeps working.

Codex hook trust

Vizhi installs its own local Codex hooks but cannot approve them for you: in Codex, run /hooks, review the Vizhi entries and trust them. Details: vizhi.dev/vizhi-codex/#hooks.

Live status (Vizhi for Claude Code)

Live status is opt-in: the plugin edits ~/.claude/settings.json only after you confirm from a Cost, Context or Activity key, keeps your own entries and backs the file up before every change. Details: vizhi.dev/claude-console/#live-status-bridge.

Windows Terminal

On Windows, import the Windows Terminal layout and run the agent in Windows Terminal, not as administrator. Details: vizhi.dev/claude-console/#windows and vizhi.dev/vizhi-codex/#windows.
